nginx is a web server - You → Linux filesystem → permissions → nginx serves files → logs show what happened
nginx = web server that can serve files or reverse-proxy to apps; config in /etc/nginx, logs in /var/log/nginx.

log folder for nginx > cd /var/log/nginx
default web files folder > cd /var/www/html
